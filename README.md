# KLTN:
Đề tài: Xây dựng website đặt đồ ăn trực tuyến với ReactJS và NodeJS tích hợp chatbot tư vấn món ăn bằng AI<br>

Sinh viên: Phạm Việt Hồng - trường đại học Công Nghệ(ĐHQGHN) - UET_VNU<br>

## Hướng dẫn cài đặt:

Để thuận tiện cho việc chạy dự án, yêu cầu:

- Nodejs v20.15.1 trở lên.
- Mongodb & Mongodb Compass.
- Có thể sử dụng VScode (https://code.visualstudio.com/) hoặc các phần mềm tương tự.

### Run:

Backend(cmd): 
```
npm start
```
Frontend/admin & Frontend/food-user(cmd):
```
npm run dev
```
